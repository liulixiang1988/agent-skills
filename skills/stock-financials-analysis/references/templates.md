# 报告输出模板

两个模板：单股深度分析 + 同业对比。两者都用中文输出，表格化呈现，配关键判断与风险提示。

## 通用规则

- **货币单位**：表头明确标注（如 "百万美元"、"亿美元"、"亿元 RMB"）
- **来源标注**：报告开头列出 `> 数据来源：[StockAnalysis.com - {ticker}](url)` 等链接
- **财年口径**：开头说明该公司财年截止月（如 "美光财年截至 8 月底"），避免读者误解
- **免责声明**：报告结尾固定加一句 `> 仅供学习研究，不构成投资建议。`
- **三段式判断**：表格之后必须有"关键判断 / 投资视角 / 风险提示"三段，不要只堆数字
- **趋势箭头**：表格最右列加一栏"趋势"，用 ↑ ↑↑ ↓ → 等符号标注 3 年走向

### 关键判断的写法要求

不要只描述数字（"营收涨了 30%"），要解释**为什么**和**意味着什么**：
- 周期反转 / 长期增长 / 一次性因素？
- 行业 beta vs 公司 alpha？
- 数据有没有警示信号（毛利率被价格补贴撑住、Capex 吃掉所有现金流等）

### 对比报告的写法要求

- **货币换算要透明**：表头同时给本币和折算后美元，避免读者算错
- **不要只比规模**：规模 + 效率（利润率）+ 资本回报（ROE/ROIC）+ 资产负债健康度，至少四个维度
- **个性对比表是灵魂**：纯财务数字看不出投资价值差异，要把"为什么投 A 不投 B"的判断显式写出来
- **可选加一节"行业份额/赛道地位"**：当主题集中在某个垂直市场（HBM、云计算、新能源车）时，纯财务对比不够，需要补行业数据
